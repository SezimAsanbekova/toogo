# Техническое задание (ТЗ)

# Веб-приложение **TooGo**

**Проект:** Сервис поиска горных мест Кыргызстана

---

# 1. Общая информация

## Название проекта
**TooGo**

## Назначение системы
TooGo — это веб-приложение для поиска горных локаций Кыргызстана, позволяющее туристам быстро находить интересные места, получать подробную информацию о них, а также находить местные туристические услуги (трансфер, проживание, гидов и др.), предоставляемые партнерами платформы.

---

# 2. Цель проекта

Разработать современное веб-приложение, которое позволит:

- предоставить удобный каталог горных мест Кыргызстана;
- помочь туристам выбрать место для путешествия;
- объединить информацию о природных достопримечательностях и туристических услугах;
- предоставить предпринимателям возможность размещать свои услуги;
- предоставить администратору инструменты управления платформой;
- создать основу для дальнейшего развития сервиса.

---

# 3. Тип системы

- **Тип:** Веб-приложение
- **Frontend:** React
- **Backend:** Spring Boot
- **База данных:** PostgreSQL

---

# 4. Пользовательские роли

## 4.1 Пользователь

Регистрация не требуется.

### Возможности пользователя

- просмотр списка горных мест;
- поиск мест по названию;
- использование фильтров;
- просмотр подробной информации о локации;
- просмотр карты;
- просмотр текущей погоды;
- добавление мест в избранное;
- использование функции **«Не могу выбрать»**.

---

## 4.2 Партнер

Для работы требуется регистрация.

После регистрации партнер получает возможность размещать собственные туристические услуги.

### Категории услуг

- трансфер (такси);
- гостевые дома;
- фрейм-домики;
- глэмпинги;
- юрты;
- гиды;
- конные прогулки;
- аренда туристического снаряжения;
- кафе;
- другие туристические услуги.

### Возможности партнера

- создание объявления;
- редактирование объявления;
- удаление объявления;
- загрузка фотографий;
- указание стоимости услуг;
- добавление контактного телефона;
- добавление WhatsApp или Telegram;
- выбор горной локации;
- просмотр своих объявлений.

---

## 4.3 Администратор

Администратор управляет всей системой.

### Возможности администратора

- добавление новых горных локаций;
- редактирование информации;
- удаление локаций;
- подтверждение объявлений партнеров;
- отклонение объявлений;
- блокировка партнеров;
- просмотр статистики системы.

---

# 5. Функциональные требования

## 5.1 Главная страница

Главная страница должна содержать:

- логотип TooGo;
- строку поиска;
- кнопку **«Не могу выбрать»**;
- блок популярных мест;
- список всех горных локаций.

---

## 5.2 Поиск

Пользователь может искать локации по названию.

Особенности поиска:

- поиск выполняется автоматически по мере ввода текста;
- результаты обновляются без перезагрузки страницы.

---

## 5.3 Фильтрация

Поддерживаются следующие фильтры:

- расстояние;
- сложность маршрута;
- стоимость посещения;
- время поездки;
- сезон посещения.

---

## 5.4 Страница горной локации

Карточка локации должна содержать:

- название;
- фотографии;
- описание;
- область;
- расстояние;
- время в пути;
- высоту;
- сложность маршрута;
- стоимость посещения;
- рекомендации;
- карту;
- текущую погоду.

### На странице также отображаются услуги партнеров

- трансфер;
- гостевые дома;
- фрейм-домики;
- глэмпинги;
- гиды;
- конные прогулки;
- кафе;
- аренда туристического снаряжения.

---

## 5.5 Избранное

Пользователь может:

- добавить место в избранное;
- удалить место из избранного;
- просмотреть сохраненные места.

> Избранное хранится локально в браузере пользователя.

---

## 5.6 Функция «Не могу выбрать»

После нажатия кнопки система случайным образом предлагает одну из доступных горных локаций.

---

## 5.7 Карта

На странице каждой локации отображается карта.

Пользователь может:

- просмотреть расположение места;
- открыть маршрут до выбранной локации.

---

## 5.8 Погода

Для каждой локации отображается:

- температура воздуха;
- погодные условия;
- скорость ветра.

---

## 5.9 Управление объявлениями (Партнер)

Партнер может:

- создать объявление;
- выбрать категорию услуги;
- выбрать горную локацию;
- добавить описание;
- загрузить фотографии;
- указать стоимость;
- указать контактные данные;
- отправить объявление на модерацию.

---

## 5.10 Модерация объявлений (Администратор)

Администратор может:

- просматривать новые объявления;
- подтверждать объявления;
- отклонять объявления с указанием причины;
- удалять объявления, нарушающие правила платформы.

---

# 6. Нефункциональные требования

## 6.1 Производительность

- загрузка страниц не более 3 секунд;
- быстрый поиск;
- корректная работа на мобильных устройствах.

---

## 6.2 Надежность

- стабильная работа приложения;
- сохранность данных пользователей и партнеров;
- минимизация ошибок при работе системы.

---

## 6.3 Безопасность

- использование HTTPS;
- защита API;
- разграничение прав доступа между ролями;
- безопасное хранение учетных данных партнеров и администратора.

---

# 7. Сценарии работы

## Пользователь

1. Открывает сайт.
2. Выполняет поиск горной локации.
3. Просматривает информацию.
4. Изучает предложения партнеров.
5. Связывается с партнером по указанным контактным данным.

---

## Партнер

1. Регистрируется.
2. Добавляет объявление.
3. Заполняет информацию об услуге.
4. Отправляет объявление на модерацию.
5. После подтверждения объявление становится доступным пользователям.

---

## Администратор

1. Входит в административную панель.
2. Проверяет новые объявления.
3. Подтверждает или отклоняет объявления.
4. Управляет информацией о горных локациях.

---

# 8. MVP (Минимально жизнеспособный продукт)

Первая версия системы включает:

- просмотр горных мест;
- поиск;
- фильтрацию;
- страницу горной локации;
- отображение карты;
- отображение текущей погоды;
- избранное;
- функцию **«Не могу выбрать»**;
- регистрацию партнеров;
- размещение объявлений;
- модерацию объявлений администратором.

---

# 9. Итог

В результате разработки должна быть создана современная веб-платформа **TooGo**, объединяющая туристов и местных предпринимателей Кыргызстана. Система позволит пользователям быстро находить подходящие горные локации и связанные с ними услуги, а партнерам — продвигать свои предложения через единую платформу.
